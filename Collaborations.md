# Groupe corpus
### Base de données partagée

- Base de données SQL hébergée au Québec
- Communique par API
- Compatible avec les normes Datascène et Artsdata
- Supporte les protocoles d’échange HTTP, HAR, JSON, cURL, WordPress, Filemaker, Node js et plusieurs autres

Le serveur DépôtCorpus incarne physiquement un réservoir commun de ressources et de données respectant la norme référentielle du ministère québécois de la culture et des communications [Datascène](https://datascene.ca/).

Le réservoir DépôtCorpus est partagé selon des profils et permissions couvrant un spectre se situant de l’ouverture publique par défaut de certains champs jusqu’à l’accès tarifé de champs privatifs à valeur ajoutée. 

Conséquemment, DépôtCorpus offre des API en lecture et en écriture permettant l’interopérabilité de ses données.
