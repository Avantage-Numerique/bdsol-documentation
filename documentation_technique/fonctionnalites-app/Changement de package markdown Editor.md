# Objectifs
Se débarrasser de quill pour un éditeur qui supporte le markdown.  
Quill a une faille que l’on contrôle, mais qui semble être prisonnier du stack du développeur.

On veut ajouter le markdown dans avnu et on est en train de choisir un package.

# Recherche de packages

## Critères
1. Open source
2. DX top + modularité
3. UX simple
4. Trace dans l'application le plus bas possible
5. ?
